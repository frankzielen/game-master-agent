# Gegenstände

Beute und Schlüsselobjekte, eine Datei pro Gegenstand, Bilder in `bilder/`. Gewöhnliche Waffen, Rüstungen und Gold werden nicht einzeln geführt. Vorlage: [_vorlagen/gegenstand.md](../../_vorlagen/gegenstand.md).
Für jedes Abenteuer kommt ein eigener Abschnitt „Neu in NN · Titel“ hinzu.
